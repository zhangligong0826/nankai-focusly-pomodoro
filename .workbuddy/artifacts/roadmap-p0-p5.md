# Focusly 改进路线图（P0–P5 六级优先级）

> 基于 2026-08-21 竞品分析与开源调研，将改进方向细化为 P0–P5 六个优先级档位。
> 每档按「地基 → 差异化 → 数据 → 社交 → 工程债 → 平台」演进，逐档打牢再进下一档。
> 每项标注：验收标准 / 预期收益 / 实施成本（低 <2 天、中 3-7 天、高 1-2 周）。

---

## P1 — 差异化核心体验（建立记忆点）

> 目标：让 Focusly 从「工具」变成「有情感归属的产品」，对齐 Forest/潮汐/番茄ToDo 被验证最强的机制。

**P1-1 可视化养成物（虚拟花园）**
- 内容：专注时长兑换植株成长，连续打卡解锁稀有品种，专注锁定触发放弃→枯萎（损失厌恶）
- 验收：完成 N 番茄后主页出现成长中的植株；连续 7 天解锁新品种；中途放弃当前植株枯萎
- 收益：Forest 用此机制种了 200 万真实树，是留存+分享最强杠杆
- 成本：高（素材 + 成长状态机）

**P1-2 热力图 + 数据复盘深化**
- 内容：GitHub 风格日历热力图、高效时段识别、打断原因记录
- 验收：热力图按日渲染专注时长深浅；统计页新增「高效时段」洞察卡
- 收益：统计从「记录」升级为「洞察」，提升复访（番茄ToDo 核心亮点）
- 成本：中

**P1-3 意图设定 + 结束反思闭环**
- 内容：专注开始前可选填「本次目标」，结束弹反思打分（Session 模式）
- 验收：开始前弹意图输入；结束后弹「目标达成？1-5 分」反思卡；数据可回看
- 收益：让每次专注有目的性，差异化显著，成本最低
- 成本：低

**P1-4 任务估时 + 番茄绑定强化**
- 内容：任务建模加「预估番茄数→预估完成时间」，计时页实时显示「今日预计完成」
- 验收：任务卡显示预估完成时间；计时页绑定任务后显示剩余番茄与预计完成点
- 收益：对齐 pomofocus「任务服务计时」核心
- 成本：低

**P1-5 白噪音场景化 + 每日金句**
- 内容：声音场景化（雨/海浪/森林/咖啡可混音）、专注前每日金句卡片
- 验收：白噪音支持多场景叠加播放；每次进入计时页显示当日金句
- 收益：对标潮汐氛围营造，声音成为第二张名片
- 成本：中低

**P1-6 锁机分级（学霸模式）**
- 内容：专注锁定升级为强锁（离开即失败+枯萎）、白名单、定时锁机（防熬夜）
- 验收：设置页可切「软提醒/强锁」；强锁下离开页面触发失败结算
- 收益：覆盖硬核自律用户（番茄ToDo 学霸模式验证）
- 成本：中

## P2 — 数据与复盘深化

**P2-1 日/周/月/年多级报告**
- 内容：在现有周/月柱状图基础上补「日报」「年报」，时间维度全覆盖
- 验收：统计页支持日/周/月/年四级切换
- 收益：对齐 pomofocus 多级可视化报告
- 成本：中

**P2-2 高效时段识别与建议**
- 内容：聚类专注时间分布，输出「你的高效时段是 20:00-22:00」类建议
- 验收：统计页出现高效时段结论卡
- 收益：数据产生行动建议，而非纯展示
- 成本：中

**P2-3 数据导出增强（周报 PDF）**
- 内容：一键生成学习周报 PDF（含图表 + 打卡 + 反思）
- 验收：设置页「导出周报 PDF」生成含图表的 PDF
- 收益：可分享、可归档，社交传播素材
- 成本：中

**P2-4 通知去重 + SW 降级通道**
- 内容：通知 tag 去重，Service Worker 通知降级（锁屏仍可收到）
- 验收：连续完成两个番茄不重复弹同标题通知；锁屏能收到
- 收益：提醒可靠性提升
- 成本：低

## P3 — 社交与增长

**P3-1 轻社交自习室（匿名陪学）**
- 内容：匿名「陪学」模式（头像+目标文字，非视频），用「有人看着」驱动打卡
- 验收：可进入自习室看到他人头像与目标，本人专注时长实时同步
- 收益：补齐外部监督机制（Focusmate/番茄ToDo 验证）
- 成本：高（需后端 + 实时通道）

**P3-2 好友专注时长榜**
- 内容：好友间周专注时长排行
- 验收：可加好友并查看排行
- 收益：社交竞争驱动
- 成本：高

**P3-3 分享卡片**
- 内容：生成「本周专注 12 番茄」精美分享卡（潮汐式）
- 验收：统计页一键生成可下载分享图
- 收益：社交传播获客
- 成本：中

---

## P4 — 工程债与质量

**P4-1 测试金字塔补齐**
- 内容：Vitest 补计时/统计纯函数单测，Playwright 补核心流程 E2E
- 验收：单测覆盖率核心逻辑 100%，E2E 覆盖「开始→完成→打卡→统计」主流程
- 收益：长期迭代安全网
- 成本：中

**P4-2 TypeScript 全量迁移**
- 内容：.js → .ts 全量迁移（基础设施已就绪，见 docs/typescript-migration.md）
- 验收：type-check 全绿且覆盖全部源文件
- 收益：类型安全，重构信心
- 成本：中

**P4-3 架构决策文档 + CI 完善**
- 内容：ARCHITECTURE-DECISIONS.md 记录关键决策；CI 加 type-check + test 门禁
- 验收：关键决策有文档；PR 自动跑 test+type-check
- 收益：对齐 super-productivity 工程实践
- 成本：低

---

## P5 — 平台与长期

**P5-1 用户体系 + 云端同步**
- 内容：登录 + 云端数据同步（换设备不丢）
- 验收：登录后数据跨设备一致
- 收益：P3 社交的前提，解决核心痛点
- 成本：高（后端 + 鉴权 + 冲突处理）

**P5-2 多端（移动 App / 桌面）**
- 内容：PWA 已可安装，进阶为原生壳（Tauri/Capacitor）或桌面托盘
- 收益：覆盖桌面常驻场景（Pomatez 验证）
- 成本：高

**P5-3 自定义皮肤/主题市场**
- 内容：用户自定义配色/背景/音效
- 收益：个性化与付费可能
- 成本：中

## 演进路线图总览

```
P0 地基(✅) → P1 差异化 → P2 数据 → P3 社交 → P4 工程债 → P5 平台
   计时正确性   养成物+复盘   多级报告   自习室+分享   测试+TS   云同步+多端
```

**建议节奏**：先做完 P1（成本低的三项：P1-3 意图复盘 / P1-4 任务估时 / P1-5 白噪音场景化 可先行，1-2 周内出差异化），再按 P2 → P4（工程债可与功能并行穿插）→ P3/P5（需后端，放长期）。

**P1 建议先做顺序**：P1-3 意图复盘（成本最低）→ P1-4 任务估时（成本低）→ P1-5 白噪音场景化（中低）→ P1-2 热力图（中）→ P1-1 养成物（高，最重磅）→ P1-6 锁机分级（中）。
