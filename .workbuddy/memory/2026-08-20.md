## UI 设计全面评审（23:38-23:50）

### 完成内容
以「像素君」（UI Designer 专家）身份对全站 36 个 Vue 组件做 7 维度设计评审，产出 `.workbuddy/artifacts/ui-review-report.md`。

### 核心发现
- 综合评分 5.9/10；设计系统基础好（CSS 变量、暗色、焦点管理齐全）
- 8 处 WCAG AA 对比度不达标（实测）：`--color-text-tertiary #999` 2.85:1 最严重；warning 2.19 / success 2.10 / info 3.15 / 白字on红按钮 3.82
- 暗色模式实际故障：WeeklyChart/MonthlyChart 硬编码 #ccc/#999/#eee，CategoryPieChart 已用运行时 cssVar 读取——同类组件两套实现
- 红线：viewport 禁缩放（maximum-scale=1.0）、无 prefers-reduced-motion、TabBar 无 safe-area-inset-bottom
- 语义色缺失：--color-primary 同时承担品牌/错误/危险操作三职
- 交互短板：任务整行不可点编辑（仅 28px 图标）、长按 3s 无进度反馈且桌面误触、select 无下拉箭头（appearance:none 后）

### 优化方案
P0（0.5天）：解缩放 + 对比度 token 修复 + 图表暗色适配 + 安全区
P1（2-3天）：页面/卡片分层、语义 token、44px 触控、整行可点、交互反馈
P2（1-2天）：间距 token、reduced-motion、tab ARIA、跟随系统主题
